## 作品定位（用户定调：双面叙事）

> **游客扫码，遇见一位金牌导游；景区点击，拥有一名数字员工。**

- **C 面 = 金牌导游体验**：看得见（全脸+表情+场景背景）、主动（迎宾/位置/天气/客流）、懂你（人格/多语言/家庭同游）、有始有终（迎宾→带游→游记明信片）。

## 演示视频三幕（窗口②先出分镜脚本+台词，不急剪片）

1. **惊艳（~30s）**：EchoMimic 英雄镜头开场 → 切实时直播，数字人在灵山雾山背景前主动迎宾。
2. **游客的一日（~4min）**：连接迎宾→拍大佛定位→亲子讲故事→今日卡看天气客流改路线→**走近九龙灌浴自动开讲（地理围栏）→转身找路，箭头跟着身体转（罗盘指路）**→英文提问→邀请家人同游→游记明信片收尾（含"今天走了 X 步"）。
3. **景区的一日（~2min）**：管理员掏出手机（管理端手机 web）30 秒换景区——上传莫高窟知识库→配形象/背景/主题→变身敦煌导游→切队友的数据大屏全景→成本对比→**片尾双二维码「评委现在就可以扫码：左游客端·右管理端」**。

## 端侧环境感知引擎（2026-06-13 用户定向：手机 web/APK 数字人须具备外界环境感知+衍生便利功能）

**统一架构**：端侧把 GPS/罗盘朝向/步程/（拉伸：噪声/光线）汇成 **context snapshot 随每次 /live/ask 上行**，与服务端已有情境注入（天气/客流/时段，env_context+crowd）合流——"主动导游"感知层闭环。这也是 APK 的产品级理由：传感器权限稳定、可后台定位，**APK 不只是壳**。

衍生功能按 评委分÷成本 排序：
1. **地理围栏主动开讲**（P0）：走近 POI 半径自动讲解"前方 50 米就是九龙灌浴…"；`/tour/nearby` 测距已有，加端侧轮询+触发去重即可；模拟位置可演示。
2. **罗盘指向性指路**（P0）：DeviceOrientation 取朝向 + 目标 bearing → overlay 箭头随身体转动实时旋转，「朝您面对的方向左转」——比静态小卡"AR 感"强一个量级（与既排期的指路 overlay 合并实现）。
3. **天气×位置便利**（P1）：下雨→自动推最近避雨点、高温→优先室内路线（FacilitySheet 设施坐标已有）。
4. **步程入游记**（P1）：游记/明信片写进"今天走了 X 步 Y 公里"；老人模式步速慢→主动建议休息点。
5. 噪声→字幕优先、天黑→夜间模式+夜游推荐（P2 拉伸，写进文档规划）。
